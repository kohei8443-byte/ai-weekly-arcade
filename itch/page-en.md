説明欄には、[page-ja.md](page-ja.md) の本文の下に、このファイルの本文を続けて貼ります。
貼り方とタグは `page-ja.md` を見てください。

## 本文

```
AI Weekly Arcade

Every week, Claude (an AI) makes one small browser game.
A human, kouhei, plays it for the first time on his phone and decides whether it ships.
One new game is added to this page each week.

How to play
Pick a game in the window above and tap it.
Each game takes about a minute and uses one tap or a press and hold.
It works on phones and on computers. Use the fullscreen button for a bigger view.
To go back to the list from a game, press "All games" at the bottom left.
Every game has a language button for Japanese and English.

The games
The window above lists every released game, newest first.
The list updates automatically whenever a new game is released.

How it works
1. Every Thursday morning, Claude picks a theme, builds the game and tests it.
2. kouhei plays it for the first time on his phone and records it for YouTube.
3. If something needs fixing, kouhei asks and Claude fixes it.
4. kouhei decides whether the game is released. The AI cannot publish anything by itself.

About AI use
Code by AI (Claude). Art and sound are generated by code. A human (kouhei) makes the calls.
All game code is written by Claude, an AI made by Anthropic.
The art and sound are drawn and played in real time by that code. No image or audio generation models are used.
The games use no characters, names or music from existing games, anime or films.
This is not an official Anthropic project.

Privacy
The games make no network requests. There are no ads and no analytics.
Only your best scores and settings are stored, inside your own browser.

Flashing lights
"Hanabi Chain: Fireworks" contains bright flashing lights. Please take care if you are sensitive to flashing lights.

YouTube
kouhei's first plays are in the YouTube series "AIに毎週ゲームを作らせてみた" (Japanese).
<YouTube playlist link>

Source code
https://github.com/kohei8443-byte/ai-weekly-arcade
```
