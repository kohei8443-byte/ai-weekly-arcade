# itch.io ページの文章（日本語）

itch.io のページ「AI Weekly Arcade」に使う日本語の文章です。
英語の文章は [page-en.md](page-en.md)、画面の設定は [settings.md](settings.md) にあります。

## 貼り方

- itch.io のページは 1 つだけです。説明欄（Description）には、このファイルの「本文」を先に、その下に `page-en.md` の「本文」を続けて貼ります。
- 説明欄はワープロのような編集画面です。Markdown の記号（`#` や `**`）は、そのままの文字として表示されます。
  本文は記号を使わずに書いてあるので、そのまま貼れます。見出しは貼ったあとに、編集画面の見出しボタンで付けてください。
- 2 つの言語の間には、編集画面の区切り線（Horizontal rule）を入れると読みやすくなります。【未確認: ボタンの名前】

## 本文

```
AI Weekly Arcade（AIに毎週ゲームを作らせてみた）

AI の Claude が、毎週 1 本、小さなゲームを作ります。
人間の kouhei がスマホで初めて遊んで、公開するかどうかを決めます。
このページには、公開が決まったゲームが毎週 1 本ずつ増えていきます。

遊び方
上の画面で、遊びたいゲームを選んでタップしてください。
どのゲームも 1 回 1 分くらいで、ワンタップか長押しで遊べます。
スマホでもパソコンでも遊べます。全画面のボタンを押すと、大きな画面で遊べます。
ゲームの画面から一覧に戻るときは、左下の「← 一覧へ」を押します。

ゲームの一覧
ゲームの一覧は、上の画面に新しい順に並んでいます。
この一覧は、新しいゲームが公開されるたびに自動で更新されます。

しくみ
1. 毎週木曜の朝、Claude がテーマを選んでゲームを作り、自分でテストします。
2. kouhei がスマホで初めて遊び、そのようすを YouTube 用に録画します。
3. 直してほしいところは、kouhei が伝えて Claude が直します。
4. 公開するかどうかは kouhei が決めます。AI が自分で公開することはできません。

AI の利用について
コードはAI（Claude）、絵と音はコードで生成、判断するのは人間（kouhei）
ゲームのプログラムは、すべて AI の Claude が書いています。
絵と音は、そのプログラムがその場で描いたり鳴らしたりしています。画像生成 AI や音声生成 AI は使っていません。
既存のゲームやアニメのキャラクター、名前、曲は使っていません。
Anthropic の公式な企画ではありません。

プライバシー
ゲームは外部と通信しません。広告もアクセス解析もありません。
ベストスコアと設定だけを、お使いのブラウザの中に保存します。

光の点滅について
「連鎖花火」には花火の強い光の点滅があります。光に敏感な方はご注意ください。

YouTube
初見プレイのようすは、YouTube のシリーズ「AIに毎週ゲームを作らせてみた」で紹介しています。
<YouTube 再生リストのリンク>

ソースコード
https://github.com/kohei8443-byte/ai-weekly-arcade
```

## メモ

- `<...>` の部分は、公開の前に kouhei が埋めます。
- 「左下の ← 一覧へ」は、`tools/hub.mjs` がゲームの画面に入れるリンクのことです。表示が変わったら、この文も直します。
- 一覧を説明欄に書き並べないのは、毎週の更新のたびに手で直すのを避けるためです。一覧は埋め込みの画面（ギャラリー）が自動で持っています。

## おすすめのタグ

itch.io のタグは 10 個までです。【未確認: 上限の数】
AI の開示で「Yes」を選ぶと「AI Generated」などのタグが自動で付くので、ここには入れません。

| タグ | 理由 |
| --- | --- |
| `arcade` | 全体のジャンル |
| `minigames` | 小さなゲームの詰め合わせであること |
| `one-button` | ほとんどのゲームがワンボタン操作 |
| `casual` | 1 回 1 分で遊べる |
| `mobile` | スマホのブラウザで遊べる |
| `short` | 短いプレイ時間 |
| `score-attack` | ベストスコアをねらう遊び方 |
| `japan` | 日本の文化をモチーフにしたゲームが多い |
| `timing` | タイミングで遊ぶゲームが多い |

`html5` は入れません。ブラウザで遊べることは、ページの種類（HTML）で表示されるためです。

ゲームが増えてきたら、各ゲームの `meta.json` の `tags` で多いものに入れかえます。
